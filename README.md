# מוסך טארק ת.ד בע״מ – אפליקציית דיווח עבודות

## איך מקבלים קישור (חינם, דרך GitHub Pages)

1. נכנסים ל-https://github.com ופותחים חשבון (אם אין).
2. לוחצים **+** למעלה ← **New repository**.
   - שם: `tarek-garage`
   - לבחור **Public** (בחינם, GitHub Pages עובד רק עם מאגר ציבורי. הקוד גלוי לכולם, אבל **נתוני המוסך לא נמצאים בו**: הם נשמרים בטלפונים).
   - לוחצים **Create repository**.
3. בעמוד שנפתח לוחצים **uploading an existing file**, גוררים פנימה את **כל הקבצים** מהתיקייה (index.html, app.js, sw.js, manifest.webmanifest, icon-180.png, icon-512.png) ולוחצים **Commit changes**.
4. **Settings** ← **Pages** ← תחת Branch בוחרים `main` ו-`/ (root)` ← **Save**.
5. אחרי דקה-שתיים יופיע הקישור:
   `https://<שם-המשתמש>.github.io/tarek-garage/`

את הקישור הזה שולחים למי שצריך לאשר.

## בטלפון (אייפון)

- לפתוח את הקישור ב-**Safari** עצמו, לא בתוך וואטסאפ או אפליקציה אחרת. רק כך המיקרופון והמצלמה עובדים.
- להוספה למסך הבית: כפתור השיתוף ← **הוסף למסך הבית**.
- בפעם הראשונה ש"מתחילים הקלטה", Safari שואל על גישה למיקרופון. לוחצים **אפשר**.
- נתוני דוגמה להצגה: מסך מנהל ← הגדרות וגיבוי ← "טען נתוני דוגמה".

## חשוב לדעת על גרסת הניסיון

- כל העבודות, ההקלטות והתמונות נשמרות **בטלפון שבו הן נרשמו**. עובדים שונים עדיין לא רואים את העבודות של השאר.
- באייפון, האפליקציה שנשמרה במסך הבית והאתר ב-Safari שומרים נתונים **בנפרד**. כדאי לבחור אחד מהם ולהישאר איתו.
- גיבוי: מסך מנהל ← הגדרות וגיבוי ← "הורד גיבוי".
- **השלב הבא:** חיבור למסד נתונים משותף בענן (למשל Firebase, יש מסלול חינמי) עם הגנה, כדי שכל העובדים יראו את אותה היסטוריה ורק מורשים ייכנסו.

## עדכון גרסה

מעלים את הקבצים החדשים לאותו מאגר (Add file ← Upload files), והטלפונים יקבלו את העדכון בפתיחה הבאה.
